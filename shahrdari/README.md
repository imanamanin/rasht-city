# میدان شهرداری رشت — تجربه سه‌بعدی

پیاده‌راه فرهنگی رشت با کاخ شهرداری، برج ساعت و تابلوهای واقعی اطراف میدان.

A static Three.js first-person walkthrough. No build step, no backend, no npm.

## باز کردن محلی

```bash
npx serve .
```

سپس بروید به `/shahrdari/`

## کنترل‌ها

| کلید | عمل |
|------|------|
| کلیک | قفل ماوس / شروع |
| WASD | حرکت |
| Mouse | نگاه |
| Space | پرش |
| Shift | دویدن |
| N | روز / شب |
| C | اول / سوم شخص |
| R | ریست موقعیت |
