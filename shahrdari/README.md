# نقشه سه‌بعدی رشت (`/shahrdari/`)

تجربهٔ تمام‌صفحه با **MapLibre GL** + تایل وکتوری **OpenFreeMap Dark** و لایهٔ `fill-extrusion` ساختمان‌ها.

## قابلیت‌ها

- دید ایزومتریک میدان شهرداری (pitch ۶۰°) تا زوم کمربندی
- مارکرهای شیشه‌ای POI با مودال، مسیریابی و اشتراک‌گذاری
- فیلتر دسته: تاریخی / خوراک / بازار / فرهنگ
- چرخش خودکار آرام دوربین با قابلیت خاموش‌کردن

## سورس مشترک

| فایل | نقش |
|------|-----|
| `../assets/js/rasht-3d-city.js` | موتور نقشه، اکستروژن، مارکرها |
| `../assets/css/rasht-3d-city.css` | UI |
| `../assets/data/rasht-pois.json` | نقاط دیدنی و مغازه‌ها |

نسخهٔ داخل صفحه اصلی: [`/#city3d`](https://rasht.city/#city3d)

فایل‌های قدیمی Three.js در همین پوشه (`main.js` و …) دیگر توسط این صفحه لود نمی‌شوند.
